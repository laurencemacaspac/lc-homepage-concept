# LC — Independent Homepage Design Concept

A responsive **Next.js 16 / React 19 / TypeScript** design preview for the LC mortgage talent marketplace. This is a standalone concept and is **not** connected to the client's existing prototype.

## Local setup

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

1. Create a new GitHub repository and upload the project files (not the outer ZIP folder).
2. In Vercel, select **Add New → Project → Import Git Repository**.
3. Keep the detected Next.js framework and default build settings; click **Deploy**.

## Included interactions

- Responsive mobile navigation
- Candidate/company experience switcher
- Concept-preview CTA modals with clear disclaimers
- Functional section links

## Not included

No authentication, database, real profiles, search backend, SMS, emails, Stripe, or other production functionality. The profile cards are **illustrative examples**, not real candidate data. The LC name is used solely to demonstrate a proposed visual direction.
